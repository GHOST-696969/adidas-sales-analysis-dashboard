# Adidas Sales Analysis Dashboard | Power BI

## Project Overview

An interactive Power BI dashboard built to analyze Adidas sales performance across different regions, states, products, retailers, and sales methods.

The dashboard provides business insights into revenue, profitability, sales trends, and product performance using interactive visualizations and DAX measures.

![Adidas Sales Dashboard](screenshots/adidas-dashboard.png)

## Key Performance Indicators (KPIs)

| KPI | Value |
|---|---:|
| Total Sales | $899.90M |
| Total Profit | $332.13M |
| Total Units Sold | 18M |
| Average Price per Unit | $45.22 |
| Profit Margin | 42.30% |

## Dashboard Features

- **Sales Performance:** Track total sales and monthly sales trends.
- **Profitability Analysis:** Monitor total profit and profit margin.
- **State-wise Analysis:** Explore sales distribution across US states using a geographical map.
- **Retailer Analysis:** Compare sales performance across different retailers.
- **Product Analysis:** Identify top-performing products based on sales.
- **Regional Analysis:** Analyze sales contribution across different regions.
- **Interactive Filters:** Filter data by month, sales method (In-store, Online, Outlet), and year (2020, 2021).

## Key Visualizations

1. KPI cards for sales, profit, units sold, average price, and profit margin.
2. Monthly Sales Trend (Area Chart).
3. State-wise Sales (Map).
4. Retailer-wise Sales (Bar Chart).
5. Product-wise Sales (Bar Chart).
6. Region-wise Sales (Donut Chart).
